Run via:
python -m SimpleHTTPServer 8080
if you're running Python 3.x or higher, use
python -m http.server 8080  (or python3 -m http.server 8080)
Now, open your browser and type http://localhost:8080/ in the URL bar and press enter or go. You should see the following visualization:![image](https://github.com/user-attachments/assets/fe22d886-e9fe-498b-accd-c33706696bca)
